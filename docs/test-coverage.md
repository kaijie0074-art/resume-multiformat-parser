# 覆盖场景说明（test-coverage.md）

17 个测试用例的覆盖矩阵。

## 路由层

| 场景 | 用例 | 断言 |
|---|---|---|
| 单栏 PDF | test_路由_单栏文本PDF | kind=pdf, text_layer=true, layout=single |
| 双栏 PDF | test_路由_双栏文本PDF | layout=multi |
| 图片型 PDF | test_路由_图片型PDF判空文本层 | text_layer=false, source=ocr |
| 不支持类型（.doc） | test_路由_不支持类型显式拒绝 | ValueError 提示 |

## 双栏重排（RPI-001 核心）

| 场景 | 用例 | 断言 |
|---|---|---|
| 职责不串公司 | test_双栏_公司A职责不串到公司B | 每家公司 desc 与真值全等 |
| **基线错挂复现** | test_双栏_基线线性抽取职责错挂_复现缺陷 | 基线至少一家错挂（缺陷固化） |
| 页眉豁免（评审#2） | test_双栏_页眉通栏不被切分_评审2 | 真实语料姓名完整在顶部 + 合成横跨词归通栏 |

## 图片型（RPI-002 核心）

| 场景 | 用例 | 断言 |
|---|---|---|
| 真实 OCR 抽出字段（env-gated） | test_图片型_真实OCR抽出全部字段 | name/phone/email/school 全对；未配置后端自动跳过 |
| 未配置显式失败 | test_图片型_无OCR后端显式失败不编造 | 抛错含"拒绝静默"+指引 |
| **基线空文本复现** | test_图片型_基线空文本全空_复现缺陷 | 基线全字段 None |

## docx（RPI-003）

| 场景 | 用例 | 断言 |
|---|---|---|
| 合并单元格去重 | test_docx_合并单元格不重复 | 学校只出现一次 |
| 表格+段落混合 | test_docx_表格与段落字段齐 | 标量与经历齐 |

## 缺失与置信度

| 场景 | 用例 | 断言 |
|---|---|---|
| 全缺失 | test_缺失字段needs_manual与告警 | needs_manual + 姓名告警 |
| 来源层置信度 | test_置信度_来源层与启发式折扣 | text=1.0/layout=0.9/ocr=0.85/docx=0.95；启发式×0.8 |
| 阈值常量钉住（评审#1/#4/#6） | test_阈值常量可追溯 | 常量值与注释依据对应 |

## 回归闸门（评估）

| 场景 | 用例 | 断言 |
|---|---|---|
| 分组 F1 下限 | test_全语料分组F1达标 | 单栏/双栏/docx≥0.95、图片型≥0.85 |
| 图片型基线=0 | test_基线在图片型上F1为零 | 0.00（空文本层是 RPI-002 根源） |
